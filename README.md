# Physik 9/10 – Stromkreise

Lernseite zur Reihe **Stromkreise** (Physik 9/10, Bildungsplan NaWi Oberschule Bremen 08/2026), nach dem Vorbild der Lernseite Energie.
Die Seite wächst mit dem Unterricht: Es steht nur, was bis zur aktuellen Doppelstunde dran war.

- Adresse: https://mr-co-osh.github.io/physik-stromkreise/
- Keine Anmeldung, kein Tracking, keine externen Dienste. Alle Schriften liegen im Repo (SIL Open Font License, siehe `assets/fonts/LIZENZEN.txt`).
- Der Lernstand wird nur im Browser des jeweiligen Geräts gespeichert.
- Regeln: `STANDARDS.md`. Lösungen und Freischalt-Codes im Klartext gehören nie in dieses Repository.
